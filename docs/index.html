FF Power Manager

Ultra-low-latency, zero-overhead Linux power profile manager and Lenovo ToF human presence sensor engine. Engineered for maximum battery endurance and instant responsiveness.

Key Features

⚡

0.0% CPU & Sub-Microsecond Speed

Hand-written x86_64 assembly routines parse ST VL53L1 sensor packets with zero CPU cycle waste. RAM usage is below 1 MB.

🔋

~5W Idle Battery Optimization

Achieves Windows-level idle power on Intel Core Ultra (Arrow Lake) via Package C8/C10 sleep, Intel Arc GuC SLPC power-saving, and kernel I/O tuning.

📡

Live ToF Presence Radar

Real-time millimeter proximity tracking. Blanks the OLED panel when you leave the desk (> 1.2m) and wakes instantly when you sit down.

🖥

Dynamic 60Hz / 120Hz + VRR

Automatically switches your 2.8K OLED screen down to 60Hz on battery (~2W direct savings) and restores 120Hz + VRR on AC power.

📊

btop-Style TUI Dashboard

Interactive multi-tab terminal UI (ff-tui) with single-key profile switching, live radar, and hardware verification.

🎨

Modern GTK4 / Libadwaita GUI

Sleek desktop app with hero telemetry cards, animated distance progress bar, and desktop app grid launcher integration.

Fast CLI Reference (ffctl)

Command Description
ffctl status Instant hardware status (Watts, battery %, refresh rate, CPU EPP, ToF distance). Runs in < 1 ms.
ffctl sensor live Stream continuous real-time distance and packet telemetry to terminal.
ffctl apply battery Apply and verify battery energy profiles directly in hardware MSRs.
ffctl apply ac Switch to full AC performance mode with 120Hz + VRR and Intel Turbo Boost.
ff-tui Launch full interactive terminal dashboard.
