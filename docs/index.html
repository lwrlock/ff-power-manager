Engineered Features

⚡

0.0% CPU & Sub-Microsecond Engine

Hand-written x86_64 assembly routines parse ST VL53L1 millimeter radar packets and write sysfs MSRs in microseconds with zero background CPU cycle waste. RAM usage < 1 MB.

🍎

MacBook-Grade Race-to-Sleep

Achieves Windows-level ~5W idle battery draw on Intel Core Ultra (Arrow Lake) without crippling the CPU. Turbo remains enabled on battery with responsive EPP so tasks burst and instantly return to C3/C8 sleep.

🎬

Zero-Stutter Intel Arc GPU & VA-API

Eliminates video stuttering in GNOME balanced mode by enforcing an 800 MHz hardware base clock floor and unlocking 2350 MHz boost, paired with hardware Intel iHD VA-API decoding.

📡

Live ToF Proximity Radar

Continuous millimeter-precision distance tracking. Automatically blanks the display when you walk away (> 1.2m) and wakes instantly when you sit down, with intelligent keyboard/mouse safety.

🖥

Dynamic 60Hz / 120Hz + VRR

Automatically switches your 2.8K OLED screen down to 60Hz on battery (~2W direct savings) and restores butter-smooth 120Hz + Variable Refresh Rate on AC power.

🚀

Hardware & System Tuning

Enforces PCIe ASPM powersupersave, auto runtime PM across 60 PCI devices, Intel Wi-Fi 7 power save, NVMe APST PS4 deep sleep, modern ZRAM zstd compression, and Google TCP BBR networking.

📊

btop-Style TUI Dashboard

Interactive terminal dashboard (ff-tui) with single-key profile switching, live millimeter radar stream, and real-time sysfs hardware verification.

🎨

Modern GTK4 / Libadwaita GUI

Sleek desktop application with hero telemetry cards, animated distance progress bar, system tray integration, and GDM login screen wallpaper synchronization.

Fast CLI Reference (ffctl)

Command Description Execution Speed
ffctl status Instant hardware status (Watts, battery %, refresh rate, CPU EPP, ToF distance). < 0.8 ms (Native C)
ffctl sensor live Stream continuous real-time distance and packet telemetry to terminal. Raw HID / Real-Time
ffctl apply battery Apply optimized battery profile (EPP balance_performance, Turbo ON, PCIe ASPM powersupersave). Direct Hardware Sysfs
ffctl apply ac Switch to full AC performance mode with 120Hz + VRR and max clocks. Direct Hardware Sysfs
ff-tui Launch full interactive terminal dashboard. Native ncurses
