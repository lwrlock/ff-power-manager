Engineered Features

⚡

Sub-Millisecond C & Assembly Core

Hand-written x86_64 assembly routines decode ST VL53L1 HID Report 4 packets and read sysfs power/thermal nodes directly via syscalls with minimal memory footprint.

🔍

Hardware Residency Audit (ffctl doctor)

Verifies [s2idle]/[deep] sleep hooks, armed ACPI wakeups, PCI Runtime PM ratios, P-state/EPP drivers, and conflicting daemons in <2ms with --json export.

🛡

Universal OEM & Lenovo ACPI Care

One-click 80% Battery Conservation (IdeaPad VPC2004 + standard charge_control_end_threshold), One-Shot 100% Charge Watchdog, Fn-Lock, and USB charge control.

🔋

Battery Health & Telemetry HUD

Real-time fuel-gauge analytics: design vs full-charge capacity (Wh), cycle count, voltage, NVMe/Wi-Fi thermals, and machine-readable JSON via ffctl health --json.

👓

GNOME Top Bar Quick Indicator

Lightweight GNOME Shell extension displaying live wattage draw, SSD/Wi-Fi °C, GPU clocks, Wh savings counter, MPRIS controls, Focus Mode, and quick profile toggles.

🎨

OLED Care & Zero-Touch Blanking

Anti-burn-in panel shift on HiDPI scales, 15s inactivity dimming, and instant DPMS screen-off when walking away without disturbing active video/audio playback.

🚀

Auto Dynamic Boost & Thermal Guardrail

Zero-overhead process watcher boosts compilers (gcc, cargo), Proton/Wine games, and local LLMs, while tapering RAPL PL1 limits at ≥90°C to prevent throttling.

🎬

Universal Intel Xe / i915 & AMD Support

Dynamically discovers P/E/LP-E cores, Intel Xe GuC SLPC, i915, and AMD Radeon DPM / k10temp nodes, pinning interactive compositor and HID/GPU IRQs cleanly.

📡

Live ToF Proximity Radar

Continuous millimeter-precision distance tracking over Intel ISH HID. Blanks display beyond 1.2m and wakes cleanly upon return, using zero webcam access.

🖥

Battery-Only Adaptive Refresh (ARR)

Drops refresh rate to 60Hz after 8s idle strictly on battery via Mutter.IdleMonitor and restores full 120Hz+ VRR at 0ms on keyboard or touchpad input.

📊

Interactive TUI Dashboard

Tabbed terminal dashboard (ff-tui) with single-key profile switching, 80% conservation toggle ([K]), live ToF radar bar, and sysfs read-back checks.

🔒

Non-Setuid Privilege Hardening

Unprivileged CLI/TUI binaries delegating privileged sysfs writes via explicit fork()/execv() PolicyKit boundaries across Ubuntu (sudo) and Fedora (wheel).

Fast CLI Reference (ffctl)

Command Description Details
ffctl status [--json] Live hardware status (Watts, battery %, CPU package temp, ARR Hz, EPP, ToF). Native C • JSON ready
ffctl doctor [--json] Inspect sleep guard hook, ACPI wakeups, PCI PM ratios, and daemon conflicts. < 2 ms Hardware Audit
ffctl health [--json] Display factory design capacity, full capacity, cycle count, and health score. Native Sysfs
ffctl conservation on|off Toggle 80% battery conservation (Lenovo VPC2004 & standard sysfs thresholds). PolicyKit / Sysfs
ffctl sensor live Stream continuous real-time distance and packet telemetry to terminal. Raw HID / Sub-ms ASM
ffctl apply [profile] Apply battery, ac, cool_quiet, max_battery, or extreme_performance. Hardware Verified
ff-tui / ff-power-manager Launch interactive terminal dashboard or GTK4/Libadwaita control center. ncurses & GTK4
